# TripSignal — website only

This is a static website only. It does not include a Python server, crawler, database, price history, or GitHub Actions workflow. Flight and hotel prices are simulated in the browser and update every 12 seconds while the page is open. All prices and listings are fictional demo data.

## Run locally

1. Extract this folder.
2. Double-click `index.html` to open it in your browser.
3. Use the Flight / Hotel tabs and filters. Prices update every 12 seconds.

For GitHub Pages, upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root, then enable Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.
