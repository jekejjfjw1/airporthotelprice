PYTHON · PLAYWRIGHT
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    responses = []
    page.on("response", lambda r: responses.append(r) if "/api/v1/" in r.url else None)
    page.goto("https://your-name.github.io/your-repo/")
    page.wait_for_timeout(1200)
    for response in responses:
        print(response.status, response.url, response.json())
    browser.close()

Playwright는 페이지 안에서 실행되는 Service Worker API 응답까지 관찰합니다. GitHub Pages는 정적 호스팅이므로 일반 requests.get()은 서비스워커가 만든 동적 응답을 실행하지 않습니다.
